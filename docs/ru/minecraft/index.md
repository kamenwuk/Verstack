# Слой Minecraft

Minecraft — слой, где байты становятся Minecraft. Здесь живут DTO пакетов, их сериализаторы и парсеры, а также диспетчер, маршрутизирующий кадры по фазам протокола. Слой организован по фазам протокола, потому что wire-формат Minecraft зависит от текущей фазы: packet id `0x00` в Handshake, Status, Login и Play значит разное, и их DTO не должны конфликтовать.

Сейчас реализованы фазы Handshake и Status полностью; фаза Login — частично (вход в фазу и разбор Login Start, без обмена шифрованием/сжатием и Login Success). Play последует.

Где этот слой в графе зависимостей — см. [Архитектуру](../architecture.md).

## Организация

```
Verstack.Minecraft/
├── Handshake/              ← фаза Handshake (DTO, парсер)
├── Status/                 ← фаза Status (DTO, сериализатор)
├── Login/                  ← фаза Login (DTO, парсер — частично)
└── Session/                ← инфраструктура сессии (фаза, диспетчер, фабрика)
```

Каждая фаза — папка в корне проекта, зеркалящая свой namespace (`Verstack.Minecraft.Status`). `Session/` отдельно: это не фаза, а каркас, общий для всех фаз — фаза соединения, диспетчер по `(фаза, packet id)` и фабрика, создающая диспетчер на каждое соединение. Он не принадлежит ни одной фазе, потому что все фазы им пользуются.

## Типы пакета

Каждый тип пакета в фазе выражается через сотрудничающие типы, разделяя данные и кодирование так, чтобы каждый можно было тестировать изолированно:

- **DTO** — `readonly struct`. Инертные поля, ноль зависимостей.
- **Сериализатор** — `static class`. Кодирует DTO в payload пакета (`VarInt` + поля); пишет только payload, фрейминг — задача `PacketFraming`. Это сторона записи.
- **Парсер** — `static class`. Декодирует payload пакета в DTO через `PacketReader`; читает тело после packet id, который уже потреблён диспетчером. Это сторона чтения, зеркало сериализатора.

Не каждый пакет имеет обе стороны: Status Request от клиента пустой — у него нет DTO; Status Response от сервера — есть сериализатор, но нет парсера (сервер его не получает). Handshake — только парсер (сервер его получает, не отправляет). Пара сериализатор/парсер появляется там, где пакет ходит в обе стороны (Login, Play).
