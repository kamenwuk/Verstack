# Слой Minecraft

Minecraft — слой, где байты становятся Minecraft. Здесь живут DTO пакетов, их сериализаторы и handler'ы, реагирующие на них. Слой организован по состояниям протокола, потому что wire-формат Minecraft зависит от текущего состояния: packet id `0x00` в Status, Login и Play значит разное, и их DTO не должны конфликтовать.

Сейчас есть только состояние Status; Login и Play последуют в том же устройстве, когда появятся.

Где этот слой в графе зависимостей — см. [Архитектуру](../architecture.md).

## Организация

```
Verstack.Minecraft/
└── Status/                    ← состояние Status
```

Каждое состояние — папка в корне проекта, зеркалящая свой namespace (`Verstack.Minecraft.Status`).

## Три актёра

Каждый тип пакета в состоянии выражается через три сотрудничающих типа, разделяя данные, кодирование и поведение так, чтобы каждый можно было тестировать изолированно:

- **DTO** — `readonly struct`. Инертные поля, ноль зависимостей.
- **Сериализатор** — `static class`. Кодирует DTO в payload пакета (`VarInt` + поля); пишет только payload, фрейминг — задача `PacketFraming`.
- **Handler** — реализация `IPacketHandler`. Реагирует на входящие payload'ы и пишет ответы; единственный актёр, касающийся соединения.
